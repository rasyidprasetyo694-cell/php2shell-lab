# Atribusi dan asal materi

Paket ini merupakan penataan repositori dan perubahan antarmuka dari arsip
`php2shell-main.zip` yang disediakan pengguna. Hash SHA-256 arsip sumber:

```text
8e2a8b0917f3e2f078db535cf938a3b1d9c22c28010c4c8b02a561bb4e557b9a
```

Dokumentasi dan atribusi lengkap dari arsip tersebut dipertahankan tanpa
perubahan pada [README-UPSTREAM.md](README-UPSTREAM.md). Dokumen asal
mengatribusikan integrasi kepada Zake / Zarxec Lab dan basis Python kepada
godylockz pada commit `a4f91107f8425a835147e27da06954023066300a`, serta
menyebut para peneliti dan kontributor lain. Atribusi ini berasal dari dokumen
arsip; paket ini belum membandingkan seluruh source terhadap commit tersebut.

Perubahan pada salinan ini mencakup halaman depan, CSS, JavaScript antarmuka,
tiga ilustrasi SVG, panduan Indonesia, launcher, serta metadata repositori.
Sebelas berkas inti lab tetap identik; rinciannya ada pada
[PRESERVASI-CORE.json](PRESERVASI-CORE.json).

Arsip asal tidak menyertakan berkas LICENSE terpisah. Paket ini tidak
menambahkan klaim lisensi MIT, Apache, atau lisensi ulang atas kode pihak ketiga.
Dokumen ini merupakan catatan asal dan perubahan, bukan pemberian lisensi.

Nama Lanud Halim Perdanakusuma digunakan sebagai tema simulasi. Halaman
menyatakan bahwa ini bukan situs resmi dan tidak berafiliasi dengan instansi
tersebut. Berita dan ilustrasinya adalah materi contoh.
